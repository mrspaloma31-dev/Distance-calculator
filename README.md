# Distance-calculator

## Description
This program uses math to calculate the distance between two points on a 2D plane

## How To Run
1. Open your computer
2. Open your program
3. run your program
4. Enter your coordinates/values

## Input Needed
• x1
• y1
• x2
• y2

## Sample output
Enter the x coordinate of the second point(x2):4
Enter the x coordinate of the second point(x1):5
Enter the y coordinate of the second point(y2):7
Enter the y coordinate of the second point(y1):8
the distance of the two points is 4.24
